# Default Community Health Files

This repository contains default community health files (like `FUNDING.yml`) that apply to all of my public repositories on GitHub.

For more about how this works, see GitHub's docs on [creating a default community health file](https://docs.github.com/en/communities/setting-up-your-project-for-healthy-contributions/creating-a-default-community-health-file).
